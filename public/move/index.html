옛 계정의 드라이브와 메일을 새 계정으로 옮깁니다.

구글의 「콘텐츠 전송」 기능을 씁니다. 자료는 구글이 직접 복사하고, 이 페이지는 아무것도 저장하지 않습니다. 아래 두 칸을 채우면 3단계 버튼이 나옵니다.

새 계정이 아직 없거나 비밀번호를 모르면 먼저 담임·담당 선생님께 받으세요. 새 계정으로 한 번은 로그인해 두어야 합니다.

1전송 페이지에서 새 계정 주소 넣기

  1. 아래 전송 페이지 열기를 누릅니다. (옛 계정으로 열립니다. 다른 계정 화면이 나오면 오른쪽 위 프로필에서 옛 계정을 고르세요.)
  2. "대상 계정 입력" 칸에 새 계정 주소를 붙여 넣습니다. (아래 새 주소 복사를 누르면 복사됩니다.)
  3. 코드 받기를 누릅니다.
전송 페이지 열기

2새 계정 메일에서 코드 받기

  1. 아래 새 계정 메일함 열기를 누릅니다. (새 계정으로 로그인하라고 하면 로그인합니다.)
  2. 구글이 보낸 "콘텐츠 전송" 메일을 열고 확인 코드 받기를 누릅니다.
  3. 나온 코드를 복사합니다. (코드는 24시간만 쓸 수 있고 한 번만 됩니다. 메일이 안 보이면 스팸함도 보세요.)
새 계정 메일함 열기

3코드 넣고 전송 시작

  1. 1단계에서 열어 둔 전송 페이지 탭으로 돌아갑니다.
  2. 코드를 붙여 넣고 확인을 누릅니다.
  3. 옮길 것(드라이브, Gmail)을 켠 채로 전송 시작을 누릅니다.

여기까지 하면 끝입니다. 전송은 보통 몇 시간, 길면 일주일 걸립니다. 끝나면 새 계정 메일로 알려 줍니다. 옛 계정의 자료는 그대로 남고, 새 계정에 복사본이 생깁니다.

수고했습니다. 이제 이 창은 닫아도 됩니다. 새 계정 드라이브와 메일함에 자료가 들어옵니다.

안 될 때
  • "이 기능을 사용할 수 없습니다"가 나오면 옛 계정의 교육청이 콘텐츠 전송을 아직 켜지 않은 것입니다. 담당 선생님께 알려 주세요. (관리자: 관리 콘솔 → 데이터 → 데이터 가져오기 및 내보내기 → Google Takeout → "콘텐츠 전송 허용", 그리고 드라이브 외부 공유 허용)
  • 코드 메일이 안 오면 새 계정 주소가 틀렸거나, 새 계정에 Gmail이 꺼져 있는 경우입니다. 주소를 다시 보고, 그래도 안 오면 담당 선생님께 알려 주세요.
  • 파일 일부가 안 왔으면 내가 소유자가 아닌 파일(남이 공유해 준 파일)이거나, 소유자가 복사를 막은 파일입니다. 그 파일은 소유자에게 새 계정으로 다시 공유해 달라고 하세요.
