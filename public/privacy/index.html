Admin Helper 개인정보처리방침

시행일 2026-11-08 (2026-11-09 사용 신청 설문 항목 추가, 2026-11-13 관리자가 입력하는 비밀번호 추가) · 적용 대상: https://adhelp.kangt.kr 과 그 하위 페이지, 크롬 확장(사이드 패널)

Admin Helper(이하 "이 서비스")는 Google Workspace 관리자가 자기 조직의 계정을 관리하도록 돕는 웹앱입니다. 이 문서는 실제 코드가 하는 일을 그대로 적은 것입니다. 코드는 github.com/Kang-T/admin-helper 에 공개돼 있어 누구나 아래 내용을 확인할 수 있습니다.

1. 한 줄 요약

이 서비스에는 서버도 데이터베이스도 없습니다. 회원가입이 없고, 관리자 본인의 구글 로그인으로 브라우저가 Google API를 직접 호출합니다. 조회하거나 변경한 사용자 정보는 관리자의 브라우저 화면에만 표시되며, 운영자를 포함해 구글 외의 어느 곳으로도 전송·저장되지 않습니다.

2. 운영자

운영자강경욱(개인, 사단법인 교사크리에이터협회)
문의·보안 신고kang@tcreator.kr

3. 처리하는 정보와 쓰임

정보어디서무엇에어디에 남나
로그인한 관리자의 이메일 주소Google OAuth(userinfo.email)화면 오른쪽 위 표시, 콘솔 바로가기를 같은 계정으로 열기, 본인 계정을 정지·삭제하지 못하게 막기브라우저 메모리. 탭을 닫으면 사라짐
조직 사용자의 정보(이름·이메일·조직 단위·계정 상태·그룹·라이선스·마지막 로그인·드라이브 사용량·클래스룸 교사 여부)Google Admin SDK 등 Google API관리자가 요청한 조회·변경 작업의 결과 표시브라우저 메모리. 어디에도 저장하지 않음
관리자가 올린 CSV 파일(신규 계정·일괄 작업)관리자 본인의 기기브라우저 안에서 읽어 Google API 요청을 만듦업로드되지 않음. 결과 CSV는 관리자 기기에 내려받기로만 생성
사용 신청 설문의 응답(관리자 계정 이메일, 선택으로 소속·메모)로그인 화면의 「사용 신청하기」 구글 설문구글 로그인 테스트 사용자로 등록하기 위해서만운영자의 구글 설문 응답 시트. 등록이 끝난 응답은 지우고, 구글 앱 검증이 끝나 신청이 필요 없어지면 설문과 응답을 모두 삭제
비밀번호(새 계정·초기화)관리자가 입력하거나 브라우저에서 생성Google API로 설정하고 화면에 한 번 표시기록하지 않음. 결과 CSV를 내려받으면 그 파일에만 남음

4. 브라우저에 남는 것

  • 로그인 토큰: 자바스크립트 메모리에만 있습니다. 쿠키·localStorage에 쓰지 않습니다. 탭을 닫거나 새로고침하면 사라지고, 로그아웃을 누르면 구글에 토큰 취소를 요청합니다.
  • 로그인 확인값(sessionStorage): 로그인 위조를 막기 위한 난수 하나. 로그인이 끝나면 지웁니다.
  • 홈 화면 바로가기 핀(localStorage): 고정한 설정 항목의 이름표 목록(예: users). 개인정보가 아닙니다.
  • 쿠키·방문 분석 도구·광고: 쓰지 않습니다.

5. 제3자에게 가는 것

상대무엇이왜
Google(API)관리자가 요청한 조회·변경 요청이 서비스의 본래 기능. 관리자가 Google Admin Console에서 직접 하는 것과 같은 요청이며, 모든 변경은 구글 관리자 감사 로그에 남습니다.
Google Fonts글꼴 요청(브라우저 IP 등 접속 정보)화면 글꼴·아이콘
Vercel(호스팅)페이지 파일 요청(브라우저 IP 등 접속 정보)정적 파일 제공. 호스팅사가 자체 접속 로그를 보존할 수 있습니다. 이 서비스가 따로 기록하는 로그는 없습니다.

그 밖의 누구에게도, 어떤 목적으로도 정보를 보내지 않습니다. 판매·광고·AI 학습에 쓰지 않습니다.

6. Google 사용자 데이터 정책 준수

이 서비스가 Google API로 받는 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다. 받은 정보는 관리자가 요청한 관리 작업을 그 자리에서 처리하는 데만 쓰고, 보관·전송·공유하지 않습니다.

요청하는 권한 범위: userinfo.email, admin.directory.user, admin.directory.group.member, admin.directory.group.readonly, admin.directory.orgunit, apps.licensing, classroom.rosters.readonly, cloud-identity.policies.readonly, admin.reports.usage.readonly, admin.datatransfer. 이 권한은 관리자 본인이 구글에서 가진 권한을 넘지 않습니다.

7. 권한 철회와 삭제

  • 로그아웃하면 토큰이 취소되고 브라우저에 남는 정보가 없습니다.
  • 구글 계정에 남은 앱 연결은 Google 계정 › 보안 › 타사 앱 액세스에서 언제든 끊을 수 있습니다.
  • 운영자에게는 삭제할 데이터가 없습니다. 아무것도 저장하지 않기 때문입니다.

8. 「내 자료 옮기기」 페이지(/move/)

로그인 없이 쓰는 안내 페이지입니다. 입력한 옛 계정·새 계정 주소는 구글 콘텐츠 전송 화면으로 가는 링크를 만드는 데만 브라우저 안에서 쓰이고, 저장되거나 전송되지 않습니다.

9. 크롬 확장(사이드 패널)

확장은 브라우저 사이드 패널에 이 웹앱을 띄우는 껍데기입니다. 요청 권한은 sidePanel 하나이며, 웹페이지 내용·탭·쿠키를 읽지 않고 따로 수집하는 것이 없습니다.

10. 변경

기능이 바뀌어 처리하는 정보가 달라지면 이 문서를 함께 고치고 맨 위 시행일을 갱신합니다. 변경 이력은 공개 저장소의 커밋 기록에서 확인할 수 있습니다.
