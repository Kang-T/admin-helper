# Admin Helper — 크롬 확장(사이드 패널)

크롬 오른쪽 사이드 패널에 웹앱을 띄우는 껍데기 확장입니다. 확장 자체는 아무 데이터도 읽거나 저장하지 않습니다
(권한은 `sidePanel` 하나뿐).

## 웹앱 주소 바꾸기 (배포 후 한 번)

`sidepanel.html`을 메모장 등으로 열고, 위쪽의 아래 줄에서 주소만 배포 주소로 바꿉니다. 끝의 `/`는 남겨 둡니다.

```
<base href="http://localhost:5173/" />
```

예: `<base href="https://aiep-admin.vercel.app/" />`

바꾼 뒤에는 아래 "확장 새로고침"을 해야 반영됩니다.

## 설치하기 (처음 한 번)

**어느 컴퓨터에서**: 확장을 쓸 컴퓨터(맥북 또는 학교 윈도우 PC)의 크롬에서 합니다.

1. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter.
2. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
3. 왼쪽 위에 새로 생긴 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
4. 폴더 선택 창에서 이 `extension` 폴더(`admin-helper/extension`)를 고르고 **선택**(윈도우는 **폴더 선택**).
5. 목록에 "Admin Helper" 카드가 생기면 성공입니다.

자주 막히는 곳:
- "매니페스트 파일이 없거나 읽을 수 없습니다" → 한 단계 위(`admin-helper`)나 아래 폴더를 고른 것입니다.
  `manifest.json`이 바로 들어 있는 `extension` 폴더를 고르세요.
- 버튼이 안 보임 → 2번의 개발자 모드가 꺼져 있는 것입니다.

## 쓰기

1. 크롬 오른쪽 위 퍼즐 조각 아이콘 → "Admin Helper" 옆 압정을 눌러 고정합니다.
2. 고정된 아이콘을 누르면 오른쪽에 사이드 패널이 열립니다.
3. 패널 안에서 로그인 창이 막히면 맨 위 **새 탭에서 열기**를 눌러 일반 탭에서 씁니다.

## 확장 새로고침 (파일을 바꾼 뒤)

`chrome://extensions` → "Admin Helper" 카드의 동그란 화살표(새로고침) 아이콘을 누릅니다.

**끝났는지 확인**: 확장 아이콘을 눌렀을 때 사이드 패널에 "Admin Helper" 화면이 보이면 됩니다.
(개발 중이면 `npm run dev`가 켜져 있어야 화면이 뜹니다.)
